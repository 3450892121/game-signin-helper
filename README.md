# 游戏社区签到助手（game-signin-helper）

Windows x64 绿色版（免安装）桌面应用：**每天自动帮你完成游戏社区签到领奖励**，支持鸣潮（库街区）、崩铁（米游社）、异环（塔吉多）三个社区，并可把当天结果汇总成一条日报发到你的 QQ。

技术栈：Electron + 原生 JavaScript（无框架、无构建步骤）+ 中文界面。

---

## ⚠️ 先读这段（使用风险与免责声明）

- 本项目的签到能力依赖各社区 App 的**非公开接口**（协议实现参考了若干同类开源项目，见[致谢](#致谢)）。自动签到**很可能违反**库洛（库街区）、米哈游（米游社）、塔吉多等服务的用户协议，导致**账号被警告、封禁或奖励回收**。
- 使用本项目产生的一切后果由使用者自行承担；权利方若要求移除相关接口实现，请开 issue 联系，我们会配合下架对应插件。
- 账号凭据（token / Cookie / 手机号）**只加密保存在你自己的电脑上**，本工具不上传到任何服务器，作者也无法获取。唯一对外的网络请求是：①官方社区接口 ②你自己在 QQ 开放平台申请的机器人接口 ③你配置的通知渠道。
- 请勿把该工具用于代他人签到、集中托管他人账号等场景。

## 功能

| | |
|---|---|
| **多游戏多账号** | 三个社区脚本随包自带，放进目录即自动加载；一个游戏可绑多个账号 |
| **自动定时签到** | 内置定时器准点执行，支持「全局时间 → 游戏时间 → 账号时间」三级覆盖 |
| **常驻可选** | 可开机自启（托盘后台跑），也可用 Windows 计划任务到点拉起补签，不必让软件常驻 |
| **签到日历** | 按月显示每天每个游戏的成功/失败，点某天看各账号明细，记录保留一年 |
| **失败告警** | 支持 Server酱 / PushPlus / 企业微信机器人 / 邮件（SMTP）四种渠道 |
| **QQ 日报** | 可选：每天把全部结果汇总成一条发到你的 QQ（失败项一并列出） |
| **凭据加密** | 用 Windows DPAPI 加密落盘；日志与界面对 token/Cookie 自动脱敏 |
| **插件化** | 框架与游戏脚本解耦，按[脚本开发规范](签到助手/docs/脚本开发规范.md)写一个 `index.js` 就能接入新游戏 |

### 各游戏登录方式

| 游戏 | 社区 | 登录方式（界面显示顺序） |
|---|---|---|
| 鸣潮 | 库街区 | 短信验证码（推荐）/ 粘贴 token / 网页登录 |
| 崩铁 | 米游社 | 网页登录（推荐，自动提取 Cookie）/ 粘贴 Cookie |
| 异环 | 塔吉多 | 短信验证码（推荐）/ 粘贴 token / 浏览器登录 |

> 短信登录若提示「需要人机验证」（极验），本工具**不绕过**验证码；改用手机上的官方 App 给同一个手机号发验证码，把收到的 6 位码填回本工具即可。

## 下载与安装（普通用户看这里）

1. 到 **[Releases](https://github.com/3450892121/game-signin-helper/releases)** 下载最新的 `游戏社区签到助手-免安装版-vX.Y.Z.7z`。
2. 解压（要整包解压，不能只拷 exe——同目录的 `.dll` / `.pak` / `locales` 必须带齐）。
3. 打开里面的「**游戏社区签到助手**」子文件夹 → 双击 `游戏社区签到助手.exe`。
   - 首次运行 Windows 可能弹蓝色「已保护你的电脑」提示：因为程序**没有代码签名**，点「更多信息」→「仍要运行」即可（只在第一次出现）。
   - 个别杀毒软件会误报 Electron 打包的未签名程序，加入信任区即可。
4. 照着同目录的 [使用教程-小白版.md](使用教程-小白版.md) 加账号、设时间。速览版见 [使用说明.txt](使用说明.txt)。

绿色版无需安装、无需管理员权限；数据都在 `%APPDATA%\签到助手`，删掉程序目录数据也不丢。

## 从源码运行（开发者看这里）

环境要求：Windows x64、Node.js ≥ 18（自带 npm）。

```bat
cd 签到助手
npm install
npm start
```

`npm start` 会直接用 Electron 加载源码运行，脚本目录取仓库根的 `脚本/`。

### 打包属于自己的绿色版

```bat
cd 签到助手
npm run release
```

一键完成：构建 `win-unpacked`（含图标与版本号注入）→ 在工作区根组装 `游戏社区签到助手-免安装版-v<版本>/`（exe 目录 + `脚本/` + 两份用户文档）→ 打同名 `.7z` → 重链系统引用 → 输出自检结果。

- 只想重链、不重新构建：`npm run release:relink`
- 跳过 7z 打包：`npm run release -- --no-7z`
- 打 7z 需要一个 7z 可执行文件：优先用工作区根的 `工具/7zr.exe`，找不到时自动改用开发依赖 `7zip-bin` 自带的 7za
- **发版脚本会写注册表 Run 键、创建 Windows 计划任务与快捷方式**，会在你本机建立自启项。不想动系统就只构建产物：`node scripts/rebuild-unpacked.js`（结果在 `签到助手/dist/win-unpacked`），不要跑 release。

## 接入一个新游戏

框架不内置任何游戏逻辑，签到能力全部来自插件。写一个插件 = 建一个文件夹 + 一个 `index.js`，至少导出 `id`、`name`、`loginMethods`、`signin` 四项，放进 `脚本/` 目录后在界面点「🔄 刷新」即生效。

完整契约、各 kind 的回调签名、凭据/结果字段、校验报错清单见 **[脚本开发规范](签到助手/docs/脚本开发规范.md)**；三个官方插件是可直接抄的完整范例。

## 数据与安全

- 用户数据目录：`%APPDATA%\签到助手`（设置、账号凭据、签到日历、日志）。
- 凭据用 Windows DPAPI（Electron `safeStorage`）加密；**若系统加密不可用会降级为明文存储**并在界面标注加密状态，此时不要把数据目录交给别人。
- 日志与界面输出对 token / Cookie / JWT / 手机号做脱敏处理（`core/redact.js`）。
- 系统计划任务只用 `签到助手-*` 前缀，不触碰其它任务。
- 详情与漏洞上报方式见 [SECURITY.md](SECURITY.md)。

## FAQ

| 问题 | 办法 |
|---|---|
| 双击 exe 没反应 | 确认是 exe 所在子文件夹里的那个 exe；检查是否被杀软隔离 |
| 提示需要人机验证（极验） | 用手机官方 App 给同一手机号发验证码，再把码填回来；崩铁改用「网页登录」 |
| 崩铁提示 cookie 无效 | 用「网页登录」，它会自动提取含 HttpOnly 的 `cookie_token_v2`；手动 F12 很容易漏这个字段 |
| 提示「登录已过期」 | 重新登录该账号 |
| 当天没签到 | 「签到日历」页下方展开「📄 运行日志」看原因；确认软件在运行或计划任务已建 |
| QQ 日报收不到 | 机器人资料卡里别关「主动消息」推送（否则报错误码 40054013）；发日报时电脑要开着 |
