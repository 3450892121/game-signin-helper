# 脚本（可安装的签到插件）

这个目录放的是「官方游戏插件」。**运行时只扫描一个脚本目录**（由 `签到助手/main.js` 的 `defaultScriptsDir()` 决定，按下面顺序取第一个存在的）：

| 运行形态 | 实际扫描的目录 |
|---|---|
| 免安装版（交付给用户） | `游戏社区签到助手-免安装版-v<版本>/脚本/` |
| 从源码开发运行 | 仓库根的 `脚本/`（也就是本目录） |
| 上面都找不到（如装进只读的 Program Files） | `%APPDATA%\签到助手\脚本\`（自动创建） |

插件**无需安装**，两种加载办法：

1. 界面里点「账号管理」→「管理游戏脚本」→「**📥 导入脚本…**」，选中插件文件夹——应用会自动拷进脚本目录、校验并立即生效（推荐）。
2. 或自己把文件夹放进上表对应的脚本目录，再点「🔄 刷新」（应用启动时也会扫描一次）。

| 文件夹 | 游戏 | 社区 | 登录方式（按界面显示顺序） |
|---|---|---|---|
| 鸣潮/ | 鸣潮 | 库街区 | 短信验证码（推荐）/ 粘贴 token / 网页登录 |
| 崩铁/ | 崩铁 | 米游社 | 网页登录（推荐，自动提取 Cookie）/ 粘贴 Cookie |
| 异环/ | 异环 | 塔吉多 | 短信验证码（推荐）/ 粘贴 token / 浏览器登录 |

> 文件夹名与游戏 id **无关**：id 由插件自己的 `index.js` 决定（`kuro` / `mihoyo` / `tajiduo`），文件夹叫什么都行。

## 想自己写一个新游戏插件？

看规范：`签到助手/docs/脚本开发规范.md`（AI 也能照着读生成）。

最简流程：新建一个文件夹（名字随便取，建议中文），里面放 `index.js`，导出插件对象——
**至少要有 `id`、`name`、`loginMethods`、`signin` 四项**（缺任一项，加载时会报校验错误并拒绝注册），
放进上面表格里对应的脚本目录，再点「🔄 刷新」即可。

参考范例：上面三个官方插件就是完整实现。
